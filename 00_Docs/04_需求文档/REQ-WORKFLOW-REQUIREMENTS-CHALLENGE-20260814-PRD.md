# PRD：独立需求质疑与双方案选择 Skill

## 范围

新增 `workflow-requirements-challenge`，处理初步 RCP 的目的质疑、可行性质疑、方案 A/B 生成、优缺点比较和用户选择，并将结果回填 RCP 后交给 Review Gate。

## 非范围

- 代码生成、固件修改、构建、烧录和目标板验证；
- Review Gate 的工程审查与门禁判定；
- Integration Plan 的文件级施工和实现 Skill 分发；
- 旧 Skill alias 或其他插件宿主的无关重构。

## 核心需求

1. 输入必须包含初步 RCP 和证据位置。
2. 输出必须包含目的质疑、可行性质疑、方案 A、方案 B、对比表和下一步选择问题。
3. 两个方案必须分别给出优点、缺点、风险、成本、验收和回滚。
4. 用户选择前状态为 `待用户选择`，不得继续下游。
5. 用户选择后记录 `selected_option`、选择理由、放弃方案和未决风险。

## 验收

通过目录、loader、路由、Skill 文本和 Jest 断言验证；不声称已完成真实模型行为评测或硬件验证。
