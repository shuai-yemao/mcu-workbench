# 0012 · 技能跟随现有归属，不为凑层强造技能

- 状态: accepted
- 日期: 2026-08-07
- 相关决策: D12

## Context

曾计划为 Platform/Impl 的每个子域建一个技能，但 platform_common/platform_middleware/impl_mcu/impl_middleware 无来源技能。

## Decision

不为空层造技能：无来源技能的层级不建独立技能，能力并入相邻技能或头文件规范承载；每个技能都有真实来源或真实业务需求。

## Consequences

技能数量收敛（42 个），每个都有依据；结构理想（子域）与技能现实解耦。
