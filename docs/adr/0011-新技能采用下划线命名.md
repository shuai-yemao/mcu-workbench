# 0011 · 新技能采用下划线命名

- 状态: accepted
- 日期: 2026-08-07
- 相关决策: D11

## Context

新技能命名曾在连字符（service-battery）与下划线（service_battery）间取舍。用户选择下划线，与目标工程目录（02_Service/service_battery）对齐。

## Decision

新技能（service_*/platform_*/impl_*/vendor_*）统一下划线命名；旧连字符 id 经 MIGRATION_MAP 自动解析。

## Consequences

插件技能名与工程目录名一一对应；旧调用名兼容；catalog 中 id 命名规则分新旧两套，需注释说明。
