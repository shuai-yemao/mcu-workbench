# 0002 · 两套分层体系：插件分层 vs 软件架构分层

- 状态: accepted
- 日期: 2026-08-07
- 相关决策: D2

## Context

workflow/tools/hardware 曾被误当作软件架构层处理。用户澄清：它们是插件的技能分层，不是软件架构分层。

## Decision

插件技能目录 = 5 个软件架构层技能（app/service/platform/impl/vendor）+ 3 个插件层技能（workflow/tools/hardware）。5 层作用于生成的嵌入式工程，3 层作用于插件自身。

## Consequences

workflow/tools/hardware 不入 5 层、不改动；软件架构文档与插件技能分层文档各自独立。
