# 0006 · 分阶段实施、每阶段独立验证可回滚

- 状态: accepted
- 日期: 2026-08-07
- 相关决策: D6

## Context

架构转化涉及 33 个技能迁移 + 11 个新增，一次性大爆炸风险高。

## Decision

按 6 阶段推进：0 定稿 → 1 Vendor 归位 → 2 Platform 契约化 → 3 Impl 落地 → 4 Service 组合 → 5 App 收敛。每阶段跑 npm test + validate:plugin/links + build:codex-compat 验证，可独立回滚。

## Consequences

风险可控、反馈快；每阶段 git 提交独立，回滚成本低。
