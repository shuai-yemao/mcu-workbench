# MPU6050 当前 Skill 基线

## 压力提示

让 MPU6050 Driver 注册到 Handle，处理 DMA/EXTI、`FromISR` 队列、回调锁边界和协作式停止，同时保留必要的旧模块级事件入口。

## 当前 Skill 可观察输出

现有 `bsp-handler` 只列出“任务、队列和缓存所有权图”与生命周期状态机；没有 ISR 上下文规则、回调锁边界、停止顺序或 API 兼容策略。

## 失败模式

- Handle 可能直接访问具体 Driver 成员而非泛化 Ops。
- ISR 可能直接做协议读写或用户回调。
- 强制删除工作线程可被当成正常停止路径。

## 合理化风险

“DMA 回调足够短，直接调用业务回调也安全。”这会使锁重入和中断延迟不可控。
