# 项目风格 profile

## 解析优先级

按以下顺序读取并记录每条规则来源；高优先级与低优先级冲突时采用高优先级：

1. 用户明确要求；
2. 目标工程的 `.editorconfig`、`.clang-format`、IDE 或构建配置；
3. 同目录或调用链相邻的 `.c/.h` 源码；
4. 保守 C 默认。

输出 profile 至少包含：来源、适用目录、缩进、制表符、大括号、行宽、命名、注释和未决项。

## 保守 C 默认

- 缩进：4 空格，无 TAB；大括号：K&R；行宽：100 列软限制；
- 命名：snake_case，不强制文件名前缀、变量前缀或类型后缀；
- 注释：最小必要注释，只保留公开 API、硬件或并发约束、非显然设计原因和复杂算法说明；
- 不强制 `ec_*`，不使用 Doxygen，不使用居中横线分隔注释，不使用 80 列硬限制。

若目标项目只有局部证据，只将该规则应用到相同目录或模块，其他字段继续向下解析。
